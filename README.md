# 煤炭市场数据图谱 V3.0 · 全量月报数据可视化

在已部署的 V2.0 基础上，新增 **2026年9月月报的21张工作表、42个Excel图表对象目录**，并支持访问者上传原始工作簿后自动读取图表原始单元格引用、批量生成图卡、切换全尺寸图、下载SVG/PNG/CSV。也支持对**任意工作表**选择日期/类别列和多条数值列直接绘制折线图；原表没有内置图表也能操作。

## 已检查原始表格

源文件：`【1】月报数据-作图-2026年09月.xlsx`（只供审查和开发使用，**不纳入公开部署包**）。

- 21张工作表：产量、晋陕蒙新、442家样本矿、进口、两种消费口径、分行业消费、电厂日耗/库存/可用天数、铁路/大秦线、环渤海港调出/库存、国内/国际煤价、产地价格等。
- 42个原Excel图表（柱线组合、折线、面积、饼图等）。
- **4个图表包含无效或外部工作簿引用**，网页标记为“引用待修复”；这些图表不会凭空生成数值。
- 原始V2.0的9个公开统计图谱继续保留，网站打开即可访问；其他完整月报指标必须由有权使用原表的访问者在浏览器中导入。

## 两类使用方式

**无需上传**：左侧“煤炭数据图谱”显示V2.0内置的9类筛选后统计序列；“月报42图·全表分析”显示42幅图的目录、来源工作表、图形类型和结构信息（不含敏感原值）。

**上传后全量分析**：左侧“月报42图·全表分析” → “选择Excel，开始绘制” → 上传原始9月工作簿 → 42个原图自动尝试关联各自数据范围并可视化 → 点选图卡全屏分析及导出。下方“工作表完整目录与自助出图”支持所有21张表，含没有原Excel图表的工作表。选中数值列后点击“生成列对比图”。

**提醒**：这是以原图数据引用重新绘制的Web图表，不是逐像素复制Excel图形（例如某些双轴、饼图样式有简化）。对原Excel中引用失效、跨文件、公式无缓存及单元格缺失的图表，仅显示可读取部分并提示复核。CSV中仅导出本次已经成功解析的数据。浏览器端XLSX组件需要通过CDN访问。

## GitHub更新操作

建议使用GitHub Desktop，不重新创建仓库：

1. 下载V3.0完整包并解压，或仅使用“V3.0增量更新包”。
2. 把下列文件复制到`Xisa520/coal-monthly-studio-public`仓库**根目录**（替换现有`index.html`/`README.md`），并保留其余文件：
   - `index.html`
   - `workbook-lab.js`
   - `workbook-lab.css`
   - `data/monthly-chart-catalog.js`、`data/monthly-chart-catalog.json`
   - `README.md`
3. 提交并推送 `main`，等待GitHub Actions中的Pages工作流成功。
4. 打开 `https://xisa520.github.io/coal-monthly-studio-public/`，按`Ctrl+F5`刷新，进入新增的“月报42图·全表分析”。

**不要上传原始Excel、Word月报或密钥到公开仓库。** `monthly-chart-catalog`文件只含结构及引用信息；公开统计数据仍来自V2.0，未逐项核验，不应直接作为正式披露数据。

## 文件说明

- `workbook-lab.js`：解析每个图表的原始单元格引用、SVG重绘、工作表自由出图及导出功能。
- `workbook-lab.css`：独立的全量图表工作台样式。
- `data/monthly-chart-catalog.js/json`：21张工作表及42个图表的目录/数据引用结构（**无原始数据值**）。
- `atlas.js/css`、`data/coal-public.js/json`：V2.0数据图谱，保留；`app.js/style.css`：原月报编辑等功能，保留。
- `.github/workflows`：原GitHub Pages部署及国家统计局候选信息检查流程，不需要因为这次更新而重建。

## 重要限制

1. GitHub Pages不能安全托管API密钥；完整自动AI写作需要有身份认证的服务端。
2. 原始Excel并未全部逐项进行数据来源和计量单位的独立核验。系统不会将原始比例值自动乘100后覆盖源数据。
3. 公开浏览者互不共享其上传数据；关闭页面后，不会永久存储本次会话的Excel。
4. 需要从根目录引用静态资源，不适合直接上传压缩包本身。
